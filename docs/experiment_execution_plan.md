## 🚀 执行计划

### Phase 1: 消融实验（优先级：P0）

#### 1.1 测试运行（推荐）

**目的**: 验证脚本正常工作

**步骤**:
1. 运行单个配置测试（如no_alignment）
2. 验证生成1-2个PRD成功
3. 检查输出格式和指标计算

**命令**:
```bash
# 可以修改脚本，只运行第一个配置和第一个Brief进行测试
python scripts/run_ablation_experiment.py
```

**预计时间**: 30分钟（测试2个PRD）

#### 1.2 完整消融实验

**目标**: 生成90个PRD（6个配置 × 15个Brief）

**预计时间**: 约27小时

**执行策略**:
- **方案A（推荐）**: 分批运行，每个配置单独运行
  - 优点: 可以随时中断和恢复
  - 缺点: 需要手动管理
- **方案B**: 一次性运行所有配置
  - 优点: 自动化程度高
  - 缺点: 如果中断需要重新开始

**监控**:
- 定期检查日志文件
- 监控API使用情况
- 检查生成的PRD数量
