# 实验步骤目的说明

## 运行 `quick_start_experiment.py` 的目的

### 一、核心目的

**验证系统功能并生成初步实验结果**，用于：
1. **系统验证**：确认多智能体系统正常工作
2. **质量评估**：计算PRD生成质量指标
3. **数据准备**：为论文实验准备数据
4. **问题发现**：识别系统问题和改进点

### 二、具体执行内容

脚本会执行以下4个步骤：

#### 步骤1：创建基准数据集
- **目的**：构建标准化的测试数据集
- **输出**：15个PRD样例的Brief JSON文件
- **用途**：
  - 作为实验的输入数据
  - 确保实验可复现
  - 覆盖14种PRD模板风格和6个领域

#### 步骤2：运行完整系统生成
- **目的**：使用多智能体系统生成PRD
- **输出**：15个完整的PRD JSON文件
- **用途**：
  - 验证系统端到端功能
  - 生成用于质量评估的PRD
  - 测试优化后的prompt和问题-解决方案分离

#### 步骤3：计算质量指标
- **目的**：评估生成的PRD质量
- **输出**：13个质量指标的数值
- **用途**：
  - 量化系统性能
  - 识别质量问题和改进方向
  - 为论文提供数据支撑

#### 步骤4：生成简要报告
- **目的**：汇总实验结果
- **输出**：Markdown格式的实验报告
- **用途**：
  - 快速查看实验结果
  - 记录实验配置和结果
  - 为论文撰写提供数据

### 四、输出结果及其用途

#### 1. 生成的PRD文件
**位置**：`results/full_system/prd_*.json`

**用途**：
- **质量评估**：计算13个质量指标
- **人工评审**：邀请产品经理评审PRD质量
- **案例分析**：在论文中展示生成的PRD样例
- **对比分析**：与基线系统和人类专家PRD对比

#### 2. 质量指标
**位置**：`results/full_system/metrics_summary.json`

**包含的指标**：
- **基础指标（5个）**：S_comp, S_mm, S_tab, S_bi, S_var
- **扩展指标（8个）**：S_sem, S_biz, S_tech, S_risk, S_expert, S_ps, S_uj, S_hyp

**用途**：
- **性能评估**：量化系统性能
- **论文数据**：在论文中展示实验结果
- **改进方向**：识别需要改进的指标

#### 3. 实验报告
**位置**：`reports/quick_report.md`

**用途**：
- **快速查看**：了解实验基本结果
- **记录存档**：保存实验配置和结果
- **论文参考**：为论文撰写提供数据

### 五、与论文实验的关系

#### 5.1 快速实验 vs 完整实验

| 特性 | 快速实验 | 完整实验 |
|------|---------|---------|
| **目的** | 验证功能、初步评估 | 完整评估、论文数据 |
| **数据集** | 15个样例 | 15个样例（可扩展） |
| **实验类型** | 完整系统 | 完整系统 + 基线 + 消融 |
| **统计检验** | 无 | 有（Wilcoxon, Cliff's δ等） |
| **时间** | 10-30分钟 | 1-2小时 |
| **输出** | 简要报告 | 完整实验报告 |

#### 5.2 论文中如何使用这些结果

**1. 系统验证部分**：
- 展示系统能够成功生成15个PRD
- 展示质量指标的初步结果
- 证明系统功能完整性

**2. 实验结果部分**：
- 使用质量指标数据制作对比表格
- 展示不同领域和模板风格的性能
- 分析问题-解决方案分离的效果

**3. 案例分析部分**：
- 选择1-2个代表性PRD进行详细分析
- 展示生成内容的质量
- 对比优化前后的差异

**4. 消融实验部分**：
- 运行消融实验（需要完整实验脚本）
- 分析各Agent的贡献
- 验证创新点的有效性

### 六、下一步行动

#### 如果快速实验成功：
1. **查看结果**：
   ```bash
   cat reports/quick_report.md
   cat results/full_system/metrics_summary.json
   ```

2. **检查生成的PRD**：
   ```bash
   # 查看一个PRD文件
   cat results/full_system/prd_*.json | head -n 100
   ```

3. **运行完整实验**（包含消融实验和统计检验）：
   ```bash
   python scripts/run_benchmark_experiment.py \
       --benchmark-dir data/benchmark \
       --output-dir results \
       --create-samples \
       --run-full-system \
       --run-ablation \
       --generate-report
   ```

#### 如果遇到问题：
1. **网络超时**：参考 `docs/network_optimization.md`
2. **质量指标低**：检查是否使用了真实模型（Qwen）
3. **生成失败**：查看错误日志，单独重试失败的PRD

### 七、实验的科学价值

#### 7.1 可复现性
- 标准化的数据集（15个样例）
- 完整的实验配置记录
- 自动化的实验流程

#### 7.2 全面性
- 13个质量指标（覆盖多个维度）
- 14种PRD模板风格（覆盖不同场景）
- 6个领域（覆盖不同应用）

#### 7.3 创新性
- 问题-解决方案空间分离（S_ps指标）
- 用户旅程完整性（S_uj指标）
- 假设验证度（S_hyp指标）

### 八、总结

**运行 `quick_start_experiment.py` 的目的是**：

1. ✅ **验证系统**：确保多智能体系统正常工作
2. ✅ **生成数据**：为论文实验准备PRD数据
3. ✅ **评估质量**：计算13个质量指标
4. ✅ **发现问题**：识别需要改进的地方
5. ✅ **准备论文**：为论文撰写提供初步数据

**这是论文实验的第一步**，后续还需要：
- 运行完整实验（包含消融实验）
- 进行统计分析（Wilcoxon检验等）
- 生成完整实验报告
- 进行人工评估（可选）
