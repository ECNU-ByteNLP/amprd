# 顶会级实验执行清单

## 📋 实验概览

- **实验目标**：验证多智能体PRD生成系统的有效性和创新性
- **总时长**：5周（35个工作日）
- **数据集**：15个Brief + 300份真实中文PRD参考
- **评估指标**：13个质量指标（5个基础 + 8个扩展）
- **对比系统**：3个基线 + 7个消融配置

## ⚠️ 风险与应对

### 风险1：真实PRD数据转换困难
- **风险**：PDF/DOC解析困难，转换耗时
- **应对**：优先处理高质量样本（48个倒推案例 + 22个大厂案例），手工标注关键章节

### 风险2：消融实验时间长
- **风险**：105个PRD生成时间长（5-7天）
- **应对**：
  1. 优先运行关键消融配置（No_Alignment, No_Vision）
  2. 并行处理（如果资源允许）
  3. 使用更小的样本集（5-10个Brief）进行快速验证

### 风险3：生成PRD质量不达标
- **风险**：生成PRD质量不够好，指标偏低
- **应对**：
  1. 使用Few-shot示例提升质量
  2. 优化Prompt（参考方法论文档）
  3. 迭代优化（根据初步结果调整）

### 风险4：API调用限制
- **风险**：Qwen API调用限制，影响实验进度
- **应对**：
  1. 增加延迟时间（动态延迟策略）
  2. 分批处理（每次处理5个PRD）
  3. 使用Mock模型进行部分测试（仅在必要时）
