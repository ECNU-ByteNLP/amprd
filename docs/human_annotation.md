# 人工轻校流程（50–80 条金标核验集）

## 目标

- 在金融/电商/医疗三个领域中，各选取 ≥15 条样本，由 PM / 研发 / QA 进行轻量标注。
- 输出对照金标，支撑自动指标校准与误差分析。

## 流程

1. **样本挑选**  
   - 使用 `src/data/annotation.py::sample_for_annotation` 基于自动门控结果挑选候选样本。  
   - 优先覆盖三领域与多平台（web/mobile/miniapp）。

2. **任务分发**  
   - `export_annotation_tasks` 生成 JSONL 清单，含路径、领域、平台、优先级、自动检测到的问题列表。  
   - 将样本与任务清单分配给对应角色（PM/Dev/QA）。

3. **标注内容**  
   - 文本修订：结构、术语、逻辑一致性。  
   - 多模态检查：界面与流程图是否与描述匹配。  
   - 指标校正：KPI/埋点是否合理。  
   - 双语对齐：中英文是否一致、术语映射是否准确。

4. **记录格式**  
   - 建议使用 Google Sheet / Airtable 或 JSON 表单，字段包括：`section_id`、`issue_type`、`suggestion`、`confidence`。

5. **整合**  
   - 将最终金标版本写回到 `data/gold/` 目录，并更新自动门控阈值或术语词表。

## 注意事项

- 标注前应签署数据使用说明与保密协议，确保敏感信息处理一致。
- 每条样本至少由两人复核，如存在分歧则由第三人裁决。
- 记录标注耗时，后续可用于成本与效率评估。
